# 倭瓜射手大冒险

一款使用 Unity 开发的 2D 横版射击游戏。控制倭瓜射手跳跃、滑翔，收集武器和法术，躲避沿途的敌人与障碍。

## 演示下载

- [观看游戏演示](https://github.com/XuJian-ty/wogua-shooter-adventure/releases/latest/download/WoguaShooterAdventure-Demo.mp4)
- [下载 Android APK](https://github.com/XuJian-ty/wogua-shooter-adventure/releases/latest/download/WoguaShooterAdventure-Android.apk)

APK 适用于 Android 64 位设备。

## 主要内容

- 两个关卡，包含不同背景、敌人、地形障碍和导弹。
- 豌豆、机枪和玉米炮等武器，支持多种法术效果。
- 单击跳跃、二段跳和长按滑翔，支持鼠标和触屏操作。
- 金币、得分、关卡解锁和本地排行榜。

## 技术栈

- Unity 6、C#、URP、Input System
- Addressables、xLua
